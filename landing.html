LESSON: The `|` operator chains commands — the output of the
left command becomes the input of the right. Use `grep` to
filter, `sort` to order, `uniq -c` to count occurrences.

CHALLENGE 12 of 54
List all unique user agents in access.log, sorted by count:

a) cat access.log | sort | uniq
b) grep "user-agent" access.log | head -20
c) cat access.log | cut -d'"' -f6 | sort | uniq -c | sort -rn
d) awk '{print $1}' access.log | sort -u

Features

Built for Real Learning

🔥
Streak Tracking
Daily streaks with bonus XP. Miss a day, lose your streak. Real motivation to show up.
⚡
Speed Records
Personal best times tracked per challenge. New records flash on screen. Get faster.
📅
Daily Challenge
One challenge per day with 2x XP bonus. Short sessions that add up.
🔖
Bookmarks
Flag any challenge for review. Revisit the ones you want to master.
⭐
Zone Star Ratings
1-3 stars based on hints used and skips. Perfect runs earn 3 stars.
🎯
Weak Spot Review
The game tracks every challenge you got wrong. Review mode drills you on your weaknesses.
📊
Difficulty Modes
Easy (free hints), Normal, Hard (1.5x XP). Adjust per zone or per session.
🏆
Completion Certificate
ASCII grade certificate on campaign completion. S through D rank based on accuracy and stars.
🔄
Auto-Updates
Checks PyPI at launch. One keypress to install the latest version and restart.
